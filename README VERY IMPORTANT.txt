To everyone that has been patient for this release, we appreciate it so much.
Early Ending was very close to being the last A.I.R. mod we had ever worked on.
We were certain a lot of people would find the concept boring, and as a result...
We actually almost never went through with this idea because of it.
Seeing just how many people adored the concept showed us we still had that
ability to come up with concepts that people like you would love the hell
out of, and it means the world to us. Thank you so much.

Please go support StarrydustNova and BriceTAS as well, as they made working
on this project a lot more fun, and it was exciting being able to set things

==MOD COMPATIBILITY==
Do keep in mind that this mod does have compatibility with a few other mods.
However, it is not compatible with any save file mods, so please beware and
back up your saves as necessary. Compatibility patches are more than welcome!

EE is compatible with the following mods:
	-Origins Parity Galore
	-Misc. Fixes & Tweaks
	-Wonder Power's Micro Mods
	-Extra Character Framework (not really... it's namely just to lock other characters out of the route.)
